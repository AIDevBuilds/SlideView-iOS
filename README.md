# SlideView (iOS)

Objective-C `UIView` (`SlideInSlideOut`) that slides in and out from an edge of the screen. It can show a table view of items.

## Configuration

Set these properties before showing the view:

- `showSlideViewWidth` and `showSlideViewHeight`: size of the sliding view
- `itemsOnTV`: the items for the table view
- `isSVShowFromBottom`: slide in from the bottom
- `doYouWantTableView`: show the items in a table view
- `colorCode`: background colour as a hex string

The sample app is in `slideInSlideOut/`.

## Run

Open the Xcode project and run the `slideInSlideOut` target.

This is an older Objective-C sample and has not been updated for current iOS versions.
